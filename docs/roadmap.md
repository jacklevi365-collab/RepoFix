# 四周交付计划

- [x] CLI、DeepSeek 工具调用、Docker 执行、轨迹和补丁
- [x] 单任务与总预算预留
- [x] 无模型费用的 scripted smoke fixture
- [ ] 真实 DeepSeek 首次任务与费用测量
- [x] 五个人工开发任务、参考补丁及固定镜像（真实仓库任务待补充）
- [x] 独立测试 ID/数量/跳过项检查与已有测试完整性检查
- [x] 增加镜像、测试收集和 Bug 复现预检（付费调用前）

## 第二周：可靠执行

- [ ] 明确环境错误、测试失败、无效补丁、重复操作等分类
- [ ] 提取结构化读文件、搜索、补丁工具并与 shell 基线比较
- [x] 可对照的确定性上下文压缩与 token/耗时记录（效果待实测）
- [ ] checkpoint 恢复，避免重放已执行操作

## 第三周：实验

- [ ] 准备至少十个独立评测任务，开发集与评测集分离
- [ ] 固定模型版本、推理模式、步数、token、环境和任务内容
- [ ] 比较简单工具循环、上下文改进、反馈策略；报告失败和超限任务
- [x] 批量执行与结果汇总入口（真实模型指标待运行）
- [ ] 记录真实成功率、回归通过率、费用、耗时与各任务轨迹
- [ ] 公开题目可能存在模型记忆，报告来源和局限

## 第四周：展示和投递

- [x] FastAPI 任务提交、查询、流式事件、幂等与中断标记
- [x] 工作台展示轨迹、diff、测试、费用和实验记录
- [ ] 一键启动、演示视频、实验报告
- [ ] 根据实测结果写简历，准备一次成功和一次失败案例讲解

## 100 元预算建议

开发 20 元、基线 25 元、优化对照 40 元、预留 15 元。先测五次真实运行的成本分布，再决定评测规模；不要为了凑任务数量消耗预留。
